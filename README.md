# MYSQL-Capstone-Project
This project focuses on analyzing purchase data from an Online learning platform using MYSQL.
# Project Title
The platform offers various digital courses to learners across different countries. Learners can purchase multiple courses, and each course belongs to a specific category.

The main objective of this project is to use SQL to explore the data and generate meaningful insights that can help management understand business performance and learner behavior.

## Project Objective
The analysis focuses on
*Identifying Sales trends
*Understanding learner purchasing behaviour
Analyzing course and category revenue,revenue performnace


## Description
The project uses a relational database consisting of tables such as:

Learners – stores learner information such as learner ID, name, and country.
Course – stores course details such as course ID, course name, category, and unit price.
Purchase – stores purchase information such as purchase ID, learner ID, course ID, quantity, purchase date, and total amount.
